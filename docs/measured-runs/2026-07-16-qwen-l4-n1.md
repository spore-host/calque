## K interpretation

At the measured ~5% occupancy the rectangle is almost entirely idle, so AWS cost
never undercuts Modal → **STAY ON MODAL**. This is the phase detector working as
designed (§9: "a tool that always says cross is a funnel"). N≈100 amortizes the
one-time load, raises occupancy, and yields the K that actually matters — see the
N=100 record.

## Caveats

- **Card substitution went further than intended.** The spike targets an RTX PRO
  6000 (g7e); g7e capacity was unavailable, so the run fell back to an L4
  (`g6.2xlarge`). The K is honest *for the L4 it ran on*, not for the intended card.
- N=1 is load-dominated by design; do not cite this occupancy/K as representative
  of batch behavior.
- The five real-hardware deployment findings surfaced by this run (worker dir
  `/opt`→`/tmp`, docker needs `sudo`, IMDSv2 hop-limit 2, 200 GiB root for the vLLM
  image, vLLM stdout vs. warm-protocol framing) are described in the README and were
  fixed + regression-tested.
