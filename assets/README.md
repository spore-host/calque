# assets

Brand/marketing graphics. Not consumed by any code path — purely for
`README.md`, the GitHub repo's social-preview card, and any future
docs-site/blog use.

- **`hero.png`** — used at the top of `README.md`.
- **`logo.png`** — icon + wordmark, transparent-ish light background. Use
  wherever a standalone logo (not the full hero banner) is needed.
- **`open-graph.png`** — 1200×630 social-preview card (Modal/GitHub link
  unfurl aspect ratio). Set as this repo's social preview image under
  **Settings → General → Social preview**, not referenced from any
  Markdown file directly.
- **`sticker.png`** — glow/die-cut treatment on a dark background, for
  physical stickers or dark-mode contexts. Not currently used anywhere.
